# d ticket 改善提案デモサイト

新入社員課題発表「お客様視点での d ticket 課題改善提案」の短期施策(3〜6ヶ月)を、
実際に触れるかたちにしたデモサイトです。

サーバー不要の静的サイト(HTML/CSS/JavaScript のみ)で、GitHub Pages でそのまま公開できます。

## 実装している改善ポイント

提案資料の「短期(3〜6ヶ月)の施策:UIを使いやすく」に対応しています。

| # | 改善 | 現状の課題 | このデモでの実装 |
|---|------|-----------|----------------|
| ① | 検索・絞り込み | 検索機能がない | キーワード・ジャンル・エリア・日程で即時絞り込み |
| ② | 興行ごとのページ | 日時順の羅列のみ | 興行単位のカード一覧+興行ページで全日程を比較 |
| ③ | 購入期間のわかりやすさ | 期間外を押すとエラー | 「受付中/受付前/受付終了」をバッジとボタンで明示、「受付中のみ表示」トグル |
| ④ | サイト内レコメンド | 案内がメール限定 | トップと興行ページに「あなたへのおすすめ」枠 |

画面右下の「💡 改善ポイントを表示」ボタンを押すと、改善箇所に番号付きの注釈が表示されます。
プレゼン中に課長・部長へ説明する際にお使いください。

## GitHub Pages での公開手順(初回のみ・約1分)

1. GitHub でこのリポジトリを開く
2. **Settings → Pages** を開く
3. 「Build and deployment」の Source で **Deploy from a branch** を選択
4. Branch に **`claude/reach-ticket-redesign-fo0z7k`**(または main にマージ後は `main`)、フォルダは **`/ (root)`** を選択して **Save**
5. 1〜2分後に `https://keita324.github.io/d_ticket/` で公開されます

## ローカルでの確認方法

`index.html` をブラウザで開くだけでも動作します。

## 注意事項

掲載しているイベント・アーティスト・価格・ポイント数はすべて架空です。
公演日や受付期間は「閲覧した日」を基準に自動生成されるため、
いつ開いても「受付中・受付前・受付終了」が混在した状態でデモできます。

## ファイル構成

```
index.html      トップページ(検索・一覧・レコメンド)
event.html      興行詳細ページ(全日程一覧・料金・関連レコメンド)
css/style.css   スタイル一式
js/data.js      デモ用データと日付ユーティリティ
js/app.js       トップページのロジック
js/event.js     興行詳細ページのロジック
```
