# d ticket 改善提案デモサイト

新入社員課題発表「お客様視点での d ticket 課題改善提案」の短期施策(3〜6ヶ月)を、
実際に触れるかたちにしたデモサイトです。

サーバー不要の静的サイト(HTML/CSS/JavaScript のみ)で、GitHub Pages でそのまま公開できます。

## 実装している改善ポイント

提案資料の「短期(3〜6ヶ月)の施策:UIを使いやすく」に対応しています。

| # | 改善 | 現状の課題 | このデモでの実装 |
|---|------|-----------|----------------|
| ① | 検索・絞り込み | 検索機能がない | キーワード・ジャンル・エリア・日程で即時絞り込み |
| ② | 興行ごとのページ | 日時順の羅列のみ | 興行単位のカード一覧+興行ページで全日程を比較 |
| ③ | 発売状況のわかりやすさ | 期間外を押すとエラー | 「発売中/発売前/受付終了」をバッジとボタンで明示、「発売中のみ表示」トグル |
| ④ | サイト内レコメンド | 案内がメール限定 | トップと興行ページに「あなたへのおすすめ」枠 |
| ⑤ | アーティスト単位の導線 | 公演を興行単位でしか辿れない | アーティストページ+興行ページに「他公演」枠 |
| ⑥ | リセール・分配への導線 | 導線が分かりづらい | ハンバーガーメニューに集約(説明つき) |

画面右下の「💡 改善ポイントを表示」ボタンを押すと、改善箇所に注釈が表示されます。
プレゼン中に課長・部長へ説明する際にお使いください。

## デザインについて

現行サイト( https://dticket.docomo.ne.jp )のトーンを踏襲しています。

- ヘッダー: ティール `#0abab5` × 白ロゴ
- 背景: ダークネイビー
- ボタン: ドコモレッド `#cb0a39` のピル型
- フォント: Noto Sans JP
- 土曜=青/日曜=赤 の日付表示

## 掲載イベントについて(最大8件)

- **実イベント4件**: 2026年6月時点で d ticket に掲載中の全イベント
  (TGC新潟/びわ湖大花火大会/TGC MATSUYAMA/第43回TGC)。
  画像は d ticket 公式サイト上の素材を直接参照(リポジトリには含めない)
- **デモ用4件**: 複数日程の比較・ジャンル絞り込み・受付終了表示など、
  改善機能を見せるための架空イベント(画像は自作SVG)

発売状況は閲覧時刻と発売期間から自動判定されるため、実イベントの「発売中/発売前」は
実サイトとほぼ同じ状態で表示されます。

## GitHub Pages での公開手順(初回のみ・約1分)

1. GitHub でこのリポジトリを開く
2. **Settings → Pages** を開く
3. 「Build and deployment」の Source で **Deploy from a branch** を選択
4. Branch に **`claude/reach-ticket-redesign-fo0z7k`**(または main にマージ後は `main`)、フォルダは **`/ (root)`** を選択して **Save**
5. 1〜2分後に `https://keita324.github.io/d_ticket/` で公開されます

## ローカルでの確認方法

`index.html` をブラウザで開くだけでも動作します。

```
css/style.css   スタイル一式

js/common.js    共通UI(カード描画・ハンバーガーメニュー・改善ポイント表示)
js/app.js       トップページのロジック
js/event.js     興行詳細ページのロジック
js/artist.js    アーティストページのロジック
images/         デモ用イベントのキービジュアル(自作SVG)
```
